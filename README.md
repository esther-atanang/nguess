# Command Line Guesser Game

A simple command-line number guessing game implemented in Python. The player has to guess a randomly generated number within a limited number of attempts.

## Installation

1. Clone the repository:
   ```
   git clone <repository-url>
   cd command-line-guesser-game
   ```

2. Install dependencies:
   ```
   pip install -r requirements.txt
   ```

## Usage

Run the game using:
```
python command_line_guesser.py
```

## Controls

- Enter: Submit your guess
- Backspace: Delete your input
- Q: Quit the game
